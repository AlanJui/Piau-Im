# 黃侃古音系統與台羅拼音（Tâi-lô）對照表

> **資料背景**：本對照表依據《說文解字》研究與應用平台（北京師範大學）所採用的**黃侃古音系統**（「古聲19紐」與「古韻28部」），整理其演變至現代台語（以《臺灣閩南語羅馬字拼音方案》文讀音與主要白話音演變趨勢為準）的系統性對應規律。

---

## 一、 黃侃「古聲19紐」與台羅聲母對照表

上古漢語的清濁對立演變至現代台語時，**全濁聲母**（定、從、群、並、匣等）大多清化，並依平仄聲調規律分化為送氣清音或不送氣清音。

> **音韻與網頁勘誤說明**：
> 1. **古無輕唇音**：後世「非、敷、奉、微」四紐在黃侃系統中歸入「邦、滂、並、明」，台語白話音大量保留此上古音特徵（如「飛」讀 `pue`、「房」讀 `pâng`）。
> 2. **古無舌上音**：後世「知、徹、澄」三紐在黃侃系統中歸入「端、透、定」，台語白話音亦多保留舌尖音讀法（如「豬」讀 `ti`、「竹」讀 `tik`、「直」讀 `ti̍t`）。
> 3. **網頁字樣勘誤**：平台界面中舌音列之「土」實為「泥」紐之誤植；牙音「見、溪、疑」三紐在界面中誤標為「齒音」。

| 發音部位 | 古聲紐 | 音韻特徵 | 台羅主要對應聲母 | 例字（上古聲紐 → 台羅拼音） |
| :--- | :--- | :--- | :--- | :--- |
| **喉音** | **影** | 清喉塞音 | **零聲母** | 安 `an`、一 `it`、衣 `i` |

| **舌音** | **端** | 舌尖清塞音 | **t** | 多 `to`、得 `tik`、知 `ti` |
| | **透** | 舌尖次清塞音 | **th** | 他 `thann`、天 `thian`、徹 `thiat` |
| | **定** | 舌尖全濁塞音 | **t / th** | 大 `tāi / tuā`、同 `tông`、頭 `thâu` |

## 二、 黃侃「古韻28部」與台羅韻母對照表

黃侃將上古韻部劃分為**陰聲**（開尾韻或元音收尾）、**入聲**（塞音韻尾 `-p, -t, -k`）、**陽聲**（鼻音韻尾 `-m, -n, -ng`）三大類別，此三分架構與現代台語的「陰、陽、入」韻尾系統高度契合。

### 1. 陰聲部（共 8 部）

上古陰聲韻部在台語中多演變為單元音或複元音開尾韻（無鼻音或塞音韻尾）。

| 古韻部 | 音韻分類 | 台羅主要對應韻母 | 例字（上古韻部 → 台羅拼音） |
| :--- | :--- | :--- | :--- |
| **歌** | 陰聲 | **o / ua / a** | 歌 `ko`、我 `guá`、麻 `muâ`、阿 `a` |
| **灰** | 陰聲 | **ue / e / ui / i** | 灰 `hue`、火 `hué`、飛 `pue`、微 `bî` |
| **齊** | 陰聲 | **e / i / ue** | 齊 `tsê`、西 `se / sai`、弟 `tē / tī`、禮 `lé` |
| **模** | 陰聲 | **oo / o / u** | 模 `bôo`、古 `kóo`、路 `lōo`、魚 `hî / hû` |
| **矦** *(侯)* | 陰聲 | **oo / au / ioo** | 侯 `hôo`、口 `khóo / kháu`、後 `hōo / āu`、句 `kù` |
| **蕭** | 陰聲 | **iau / io / iu** | 蕭 `siau`、笑 `tshiò`、求 `kiû`、鳥 `tsiáu` |
| **豪** | 陰聲 | **o / au** | 豪 `hô`、高 `ko`、老 `nó / lāu`、道 `tō` |
| **咍** | 陰聲 | **ai / i / ue** | 台 `tâi`、海 `hái`、來 `lâi`、之 `tsi`、梅 `muî / muê` |

### 2. 入聲部（共 10 部）

上古入聲韻部在台語中完整保留 `-p`、`-t`、`-k` 三套塞音韻尾（白話音部分弱化為喉塞音 `-h`）。

| 古韻部 | 韻尾類別 | 台羅主要對應韻母 | 例字（上古韻部 → 台羅拼音） |
| :--- | :--- | :--- | :--- |
| **曷** | `-t` 尾 | **at / uat / eh** | 割 `kat`、月 `gua̍t`、八 `pat / pueh`、達 `ta̍t` |
| **沒** | `-t` 尾 | **ut / it / uat** | 沒 `bu̍t`、骨 `kut`、物 `bu̍t / mi̍h`、出 `tshut` |
| **屑** | `-t` 尾 | **iat / it / ih** | 屑 `siat`、結 `kiat`、鐵 `thiat / thih`、一 `it` |
| **帖** *(網頁連排「貼文」)* | `-p` 尾 | **iap / ap** | 帖 `thiap`、葉 `ia̍p / hio̍h`、接 `tsiap`、涉 `sia̍p` |
| **合** | `-p` 尾 | **ap / ah** | 合 `ha̍p / ka̍h`、答 `tap`、十 `si̍p / tsa̍p`、納 `la̍p` |
| **錫** | `-k` 尾 | **ik / iah / eh** | 錫 `sik / siah`、白 `pi̍k / pe̍h`、壁 `piah`、帝 `tè` *(去聲化)* |
| **鐸** | `-k` 尾 | **ok / oh / ak** | 鐸 `to̍k`、落 `lo̍k / la̍uh`、學 `ha̍k`、作 `tsok / tsò` |
| **屋** | `-k` 尾 | **ok / iok / ak** | 屋 `ok`、木 `bo̍k`、六 `lio̍k / la̍k`、讀 `tho̍k / tha̍k` |
| **沃** | `-k` 尾 | **ok / au / ioh** | 沃 `ak`、藥 `io̍k / io̍h`、告 `kò` *(去聲化)*、學 `ha̍k` |
| **德** | `-k` 尾 | **ik / it / ak** | 德 `tik`、北 `pak`、國 `kok`、得 `tik`、黑 `hik / oo` |

| **覃** | `-m` 尾 | **am / im** | 覃 `thâm`、南 `lâm`、心 `sim`、音 `im`、感 `kám` |

| **青** | `-ng` 尾 | **ing / inn / enn** | 青 `tshing / tshinn`、生 `sing / senn`、名 `bîng / miâ`、平 `pîng` |
| **唐** | `-ng` 尾 | **ong / ang / iong** | 唐 `tông`、方 `hong / hng`、長 `tiông / tn̂g`、上 `siōng` |
| **東** | `-ng` 尾 | **ong / iong / ang** | 東 `tong`、工 `kang`、中 `tiong`、公 `kong`、同 `tông` |

## 三、 上古音（黃侃系統）與台語對應核心總結

1. **聲母演變三原則**：
   * **全濁清化**：古全濁聲母（定、從、並）在台語中依平仄分化為送氣或不送氣清音（如「平」`pîng` 不送氣、「皮」`phuê` 送氣）。
   * **存古特徵**：台語白話音完整保留「古無輕唇音」（幫系讀 `p/ph/b`）與「古無舌上音」（端系讀 `t/th`）。
   * **鼻音演變**：古明紐、泥紐、疑紐在台語文讀音中多去鼻化為濁塞音 `b`、`l`、`g`，白話音則保留鼻音 `m`、`n`、`ng`。
2. **韻尾系統高度對應**：
   * 黃侃「陰、入、陽」三類韻部與台語韻尾呈現極為整齊的歷史層次對應：
     * **陰聲 8 部** $ightarrow$ 開尾韻（元音結尾）
     * **入聲 10 部** $ightarrow$ 塞音韻尾（`-p, -t, -k` 及喉塞音 `-h`）
     * **陽聲 10 部** $ightarrow$ 鼻音韻尾（`-m, -n, -ng` 及鼻化韻 `-nn`）
